# Проєкт: інструмент масової подачі форми (тестове завдання)

Нейтральні правила для цієї теки. Імен компаній, замовників, доменів клієнтів тут немає і бути не повинно.

- Мова коментарів і README: українська, прості формулювання. Без довгих тире, лапки прямі.
- У код і README не потрапляють: прізвища, назви компаній, реальні домени цілей, ключі і токени. Дані лише example.com або вигадані.
- Обхід захисту (капча, антибот, ліміти) не реалізуємо. Капчу і фінальний сабміт робить людина.
- Секрети лише в .env (у git не йде). У репозиторії лише .env.example без значень.
- Перед здачею: git log звірити на нейтральне ім'я і пошту; в архів не класти .git, .env, __pycache__, *.db, uploads.
